Sensors not working? Use phyphox
  1. Install the free app phyphox (App Store / Play Store).
  2. Open Acceleration with g (or Gyroscope). Menu ⋮ → Timed run: delay 2 s, duration 3 s.
  3. Press ▶, do the gesture once when it starts.
  4. Menu ⋮ → Export data → CSV (Comma, decimal point) → save to Files.
  5. Pick the gesture above, choose the file here, upload. One file per take.
